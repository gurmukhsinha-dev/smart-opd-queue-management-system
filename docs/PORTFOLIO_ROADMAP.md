# Smart OPD Portfolio Roadmap

This repository is being polished as a recruiter-facing Python project. The goal is to show that the project is not only a demo, but an engineered system with tests, CI, deployment thinking, documentation, and clear product reasoning.

## Recruiter Signal

- Python backend with queue orchestration logic.
- Healthcare domain problem with realistic operational constraints.
- React frontend for patient, doctor, and admin workflows.
- MySQL persistence and Docker-based deployment setup.
- ML wait-time prediction module.
- CI, tests, and daily engineering notes.

## Daily Contribution Rule

Every day should produce a real commit with one clear learning outcome and one visible engineering improvement. Green contribution squares are useful, but the history must also tell a believable story of progress.
